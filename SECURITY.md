# Security

If a blueprint would lead an agent to build something insecure, such as access
checked only in the browser, credentials in code, or personal data exposed to
the wrong role, please do not describe it in a public issue.

Use **Report a vulnerability** on this repository's Security tab. If that
button is not available, open an issue titled "Security contact request" with no
details, and we will contact you privately. We aim to acknowledge reports within three
working days.
